# LangChain RAG Pipeline

A Retrieval-Augmented Generation (RAG) pipeline implementation using LangChain and LangGraph. This project provides a flexible document processing system that can ingest various file types, store them in a vector database, and generate high-quality responses to queries by combining relevant retrieved context with large language model capabilities.

## Key Features
- Document ingestion (PDF, TXT, MD, Python)
- Vector store management
- Advanced RAG pipeline with feedback loops
- Comprehensive evaluation metrics
